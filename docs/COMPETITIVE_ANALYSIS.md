# RSS 阅读器竞品分析

> 调研主流 RSS 工具的功能、痛点和创新机会

---

## 🔍 主要竞品

### 1. Folo (原 Follow)
**定位**: AI-first RSS 阅读器，开源
**价格**: 免费 + 付费 AI 功能

**优秀功能**:
- ✨ AI 翻译、摘要、智能推荐
- 📱 全平台：Web/iOS/Android/macOS/Windows/Linux
- 🎨 精美 UI，支持多种内容类型（文章/视频/图片/音频）
- 👥 社区驱动，可分享订阅列表
- 🔗 统一时间线，聚合多源内容

**痛点**:
- 部署成本高（需要云服务）
- AI 功能依赖官方服务，无法自托管 AI
- 同步功能依赖官方服务器

### 2. Feedly
**定位**: 企业级信息聚合平台
**价格**: 免费版有限，Pro $6/月，Team $18/月

**优秀功能**:
- 🔍 强大的发现功能，自动推荐相关源
- 🏷️ AI 驱动的主题追踪和品牌监控
- 📊 威胁情报和市场情报模块
- 🔗 丰富的第三方集成 (Slack, Teams, Zapier)
- 📰 Newsletter 订阅整合到 Feed

**痛点**:
- 免费版限制太多（100 源，3 文件夹）
- 不开源，无法自托管
- UI 相对老旧
- 贵！团队版太贵

### 3. Inoreader
**定位**: 功能全面的 RSS 阅读器
**价格**: 免费版有限，Pro $5/月

**优秀功能**:
- 🔍 全局搜索（不只是订阅内容）
- 📧 Newsletter 转 RSS
- 📺 YouTube 订阅同步
- 🔔 Google News Alerts 集成
- 🕵️ 网页变化监控
- 💾 保存网页到稍后读

**痛点**:
- 免费版广告多
- UI 不够现代
- 不开源
- AI 功能弱

### 4. Readwise Reader
**定位**: Power Reader 的一体化阅读工具
**价格**: $8.99/月（含 Readwise 服务）

**优秀功能**:
- 📝 一流的高亮和批注体验
- 📚 支持多种格式：RSS/PDF/EPUB/YouTube/Twitter/Newsletter
- 🔄 Daily Review - 间隔重复复习高亮
- 🔗 自动同步到 Notion/Obsidian/Roam
- 🖥️ 网页高亮浏览器插件

**痛点**:
- 贵！需要同时订阅 Readwise
- 不开源
- 无自托管选项
- AI 功能不突出

### 5. Miniflux (我们的后端)
**定位**: 极简主义自托管 RSS 阅读器
**价格**: 免费开源

**优秀功能**:
- 🔒 隐私保护：去追踪像素、剥离 UTM 参数
- 📰 全文抓取（Readability）
- 🎨 极简无干扰 UI
- ⌨️ 键盘快捷键
- 🔗 25+ 第三方集成
- 💾 PostgreSQL 全文搜索

**痛点**:
- UI 太简陋
- 无 AI 功能
- 无移动 App
- 无社交/分享功能

## 💡 痛点总结 & 创新机会

### 用户普遍痛点

1. **信息过载**
   - 订阅太多，看不完
   - 没有优先级排序
   - 重要内容被淹没

2. **AI 功能不够智能**
   - 摘要质量参差不齐
   - 翻译不够准确
   - 缺乏个性化推荐

3. **自托管体验差**
   - 部署复杂
   - UI 简陋
   - 缺少移动端

4. **知识管理割裂**
   - 阅读和笔记分离
   - 高亮难以导出
   - 无法形成知识网络

5. **订阅发现困难**
   - 不知道订阅什么
   - RSS 地址难找
   - 缺少推荐机制

## 🚀 FeedGlow 创新方向

### P0 - 差异化核心功能

1. **智能优先级排序** ⭐
   - AI 学习用户阅读习惯
   - 自动识别重要/紧急文章
   - "For You" 个性化推荐 Feed
   - *竞品都没做好这个*

2. **AI 深度阅读助手** ⭐
   - 不只是摘要，支持问答对话
   - "这篇文章的核心观点是什么？"
   - "与我之前读的 XX 有什么关联？"
   - 跨文章知识关联
   - *Readwise 有一点，但不够深*

3. **一键自托管** ⭐
   - Docker 一键部署
   - 带 AI 的完整方案
   - 支持 Ollama 本地模型
   - *Folo 无法自托管 AI*

### P1 - 体验优化

4. **沉浸式阅读模式**
   - 去除所有干扰
   - 自定义排版
   - 护眼模式
   - 阅读进度记忆

5. **智能订阅发现**
   - 基于已订阅内容推荐
   - 热门/趋势订阅榜
   - 订阅列表分享/导入
   - RSS 地址自动发现

6. **Newsletter 整合**
   - 邮箱转 RSS
   - Newsletter 和 RSS 统一管理
   - *Inoreader/Feedly 有，但体验一般*

### P2 - 高级功能

7. **知识图谱**
   - 文章间自动关联
   - 标签/主题聚类
   - 可视化知识网络
   - *没有竞品做这个*

8. **阅读数据分析**
   - 阅读时长统计
   - 主题偏好分析
   - 阅读习惯趋势
   - "本周你关注最多的是..."

9. **协作功能**
   - 团队共享订阅
   - 文章评论讨论
   - 高亮分享
   - *Feedly Team 很贵，我们可以免费*

10. **跨平台同步**
    - Web/iOS/Android
    - 离线阅读
    - 阅读进度同步
    - 书签/高亮同步
